1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
The Sinka Admin Dashboard now features a complete, professional, production-grade
Product Management UI seamlessly integrated with the backend REST API and Cloudflare
R2 object storage service.

Key Features & Achievements:
  1. Product Catalogue Management:
     - Search by title, description, or SKU.
     - Category filtering across all 10 canonical Sinka furniture categories.
     - Status filtering (All, Active, Inactive, Featured).
     - Flexible sorting (Newest, Price: Low to High, Price: High to Low, Stock, Name).
     - Responsive data table displaying cover thumbnails, pricing (with MRP strikethrough
       and discount % calculations), stock indicators, active/featured badges, and actions.
     - Server-side pagination with item count indicators.
  2. Cloudflare R2 Image Upload Integration:
     - Integrates with dedicated backend upload endpoint: POST /api/admin/upload/products.
     - Supports up to 10 images per batch, max 8 MB per file (JPEG, PNG, WebP, AVIF).
     - Multi-image file picker & drag-and-drop zone.
     - Real-time upload progress bar and error feedback.
     - Gallery manager allowing image reordering (left/right sequence), selecting the
       primary/cover image (stored at index 0), adding accessible alt text, and safe removal.
     - Clean separation: Local file paths or raw binaries are never submitted to the
       product database; only public CDN URLs and 'products/' R2 keys are stored.
     - Zero credential leakage: R2 secret keys and access tokens remain exclusively
       on the backend.
  3. Product Creation & Editing Workflows:
     - Unified, accessible form supporting creation (/products/new) and editing
       (/products/:id/edit).
     - Auto-generated URL slug derived from product title (with manual override option).
     - Canonical category selection dropdown.
     - Pricing validation (selling price, MRP, automatic savings calculation).
     - Inventory tracking (stock quantity, SKU code, automated Low Stock / Out of Stock states).
     - Interactive Storefront Live Preview card simulating real customer card appearance.
     - Prevents accidental data loss or double submissions during asynchronous requests.
  4. Product Detail & Quick Inspection:
     - Modal viewer for rapid inspection of all product specifications, complete R2
       image gallery, pricing savings, inventory status, and R2 object keys.
  5. Security & Isolation:
     - Uses 24-hour dedicated Admin JWT Bearer authentication via centralized apiClient.
     - Automatic FormData boundary generation (never overrides multipart Content-Type).
     - Customer storefront (sinka-frontend) and backend codebase remained untouched.

3. API MAPPINGS & ENDPOINTS

Authorization: Bearer <ADMIN_JWT>.

  - Method: GET
  - Path: /api/admin/products
  - Query Parameters:
      page=1&limit=10&search=sofa&category=sofas&isActive=true&isFeatured=all&sort=createdAt:desc

Endpoint 2: Get Product by ID
  - Method: GET
  - Path: /api/admin/products/:id
  - Response (200 OK):
    { "success": true, "data": { "product": { ... } } }

Endpoint 3: Create Product
  - Method: POST
  - Path: /api/admin/products
  - Body:
    {
      "name": "Artisan Teak 3-Seater Sofa",
      "slug": "artisan-teak-3-seater-sofa",
      "description": "Handcrafted solid teak sofa with high-density foam cushions.",
      "category": "sofas",

      "sku": "SOF-TEAK-001",
      "isActive": true,
      "isFeatured": false,
      "images": [
        {
          "url": "https://pub-...r2.dev/products/173022...webp",
          "key": "products/173022...webp",
          "alt": "Front view"
        }
      ]
    }
  - Response (201 Created):
    { "success": true, "data": { "product": { ... } } }

Endpoint 4: Update Product
  - Method: PATCH (and PUT)
  - Path: /api/admin/products/:id
  - Body: Partial update object conforming to updateProductSchema.
  - Response (200 OK):
    { "success": true, "data": { "product": { ... } } }

Endpoint 5: Delete Product
  - Method: DELETE
  - Path: /api/admin/products/:id
  - Response (200 OK):
    { "success": true, "data": { "product": { "id": "...", "deleted": true } } }

Endpoint 6: Upload Product Images to Cloudflare R2
  - Method: POST
  - Path: /api/admin/upload/products
  - Headers: Authorization: Bearer <ADMIN_JWT> (Browser sets Content-Type boundary)
  - Payload: FormData with field 'images' (File[])
  - Constraints: Max 10 files per batch, max 8 MB per file, JPEG/PNG/WebP/AVIF.
  - Response (201 Created):
    {
      "success": true,
      "message": "2 image(s) uploaded successfully",
      "data": {
