1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
The Homepage Banner creation experience and live preview in the Sinka Admin Dashboard
have been comprehensively overhauled to support pure image banners and flexible,
optional narrative overlays:

Key Improvements:
  1. Master Text Overlay Toggle:
     - Prominent "Show Text Overlay" switch (Default: OFF).
     - When OFF (Pure Image Banner):
       * The customer carousel renders the edge-to-edge artwork in full clarity.
       * The dark gradient scrim and narrative text containers are omitted.
       * Admins can upload an image and publish immediately without entering any text.
     - When ON (Narrative Overlay):
       * Renders the directional gradient overlay and only enabled content elements.
  2. Four Independent Sub-Toggles:
     - Show Eyebrow Label (Default: OFF): Reveals eyebrow text input (max 100 chars).
     - Show Main Headline (Default: OFF): Reveals headline text input (max 150 chars,
       validated only when ON).
     - Show Subtitle (Default: OFF): Reveals subtitle textarea (max 300 chars).
     - Show Call to Action (CTA) Button (Default: OFF): Reveals CTA button label &
       destination URL inputs.
     - When any toggle is OFF, its inputs are hidden and cleanly saved as empty strings
       (preventing stale values from being submitted).
  3. Live Storefront Carousel Preview Overhaul:
     - Prominent full-width preview positioned right beneath the page header, providing
       realistic desktop proportions (aspect-16/9 and aspect-21/9, min-height 420px-480px).
     - Eliminated text overlap: Generous padding (px-8 to px-24, py-10 to py-16) ensures
       typography never collides with navigation arrows or bottom slide indicators.
     - Directional gradient scrim is rendered ONLY when text content exists.
     - Added an interactive Viewport Switcher ("Desktop Widescreen" vs "Mobile View"),
       enabling administrators to test responsive behavior directly from the admin panel.
     - Instant reactivity: The preview updates immediately as the administrator types,
       toggles switches, or uploads new imagery.
  4. Backend Compatibility & Migration Safety:
     - Updated Sinka-backend Mongoose model (`models/banner.model.js`) and Zod validation
       schemas (`validation/banner.schema.js`) so that `title` is optional with default `''`.
     - Preserves 100% backwards compatibility with all existing banners.
     - Edit mode automatically restores all toggle states from saved banner records:
       if an older banner has a title, eyebrow, subtitle, or CTA, its respective toggles
       and master overlay toggle are seamlessly set to ON.

3. PREVIEW & UI COMPARISON
--------------------------------------------------------------------------------
Before:
  - Preview was crammed into a narrow 5-column side box (~400px wide, ~190px tall).
  - Headline, subtitle, CTA button, and internal debug badges were all rendered by default.
  - Text collided directly with the left arrow and bottom slide indicator dots.
  - Always showed dark gradient scrim regardless of whether text existed.

After:
  - Preview is given full container width at the top with authentic 21:9 storefront aspect ratio.
  - Pure Image Banner (Default): Displays edge-to-edge photography with zero gradient overlay
    and zero text.

    eyebrow with accent pill, bold headline, subtitle, and CTA button in their exact
    storefront positions with ample breathing room.
  - Responsive Viewport Switcher: Allows previewing desktop widescreen vs mobile layout.
