1. EXECUTIVE SUMMARY
================================================================================

A comprehensive, production-grade Order Management Interface has been implemented
in the Sinka Admin Dashboard (`sinka-admin`).

The order management module allows back-office administrators to:
  1. Inspect and filter customer orders with real-time multi-field search,
     lifecycle status tabs, payment status filters, date range filters, and pagination.
  2. Inspect complete order details including customer snapshots, delivery addresses,
     immutable order item snapshots with thumbnails and SKU/variants, and full pricing breakdown.
  3. Manage order lifecycle status transitions governed strictly by the backend state machine,
     with confirmation modals, optional admin notes, and automated inventory restoration warnings.
  4. Assign and update logistics courier tracking (Delhivery, BlueDart, DTDC, IndiaPost, Shiprocket,
     and custom carriers) with auto-generated tracking links and auto-ship progression.
  5. Audit lifecycle history timelines and append internal administrative notes.
  6. Present all monetary values consistently in canonical Indian Rupee currency format (e.g. ₹45,000).

4. BACKEND REST API INTEGRATION
================================================================================

All requests interface with the dedicated administrative order controller in `Sinka-backend`:
  - `GET /api/admin/orders`:
    * Query params: `page`, `limit`, `search`, `status`, `paymentStatus`, `startDate`, `endDate`, `sort`
  - `GET /api/admin/orders/:orderId`:
    * Resolves order by MongoDB ObjectId or human-readable orderNumber (e.g. `ORD-...`)
  - `PATCH /api/admin/orders/:orderId/status`:
    * Payload: `{ status, note }`
    * Validates lifecycle state machine; rejects invalid jumps; triggers async customer emails.
  - `PATCH /api/admin/orders/:orderId/tracking`:
    * Payload: `{ courierName, trackingId, trackingUrl, shipmentDate, shippingNote }`
    * Automatically advances order to `SHIPPED` if in `PENDING`, `ACCEPTED`, `PROCESSING`, or `PACKED`.
  - `PATCH /api/admin/orders/:orderId/admin-note`:
    * Payload: `{ note }`
    * Appends internal administrative note without modifying customer-visible timeline.

5. LIFECYCLE STATE MACHINE VALIDATION
================================================================================

Strictly aligned with backend `orderStatus.service.js`:
  - PENDING          -> ACCEPTED, CANCELLED, REJECTED
  - ACCEPTED         -> PROCESSING, CANCELLED
  - PROCESSING       -> PACKED, CANCELLED
  - PACKED           -> SHIPPED, CANCELLED
  - SHIPPED          -> OUT_FOR_DELIVERY, DELIVERED, CANCELLED
  - OUT_FOR_DELIVERY -> DELIVERED, CANCELLED
  - DELIVERED        -> Terminal (No transitions)
  - CANCELLED        -> Terminal (Restores inventory)
  - REJECTED         -> Terminal (Restores inventory)
