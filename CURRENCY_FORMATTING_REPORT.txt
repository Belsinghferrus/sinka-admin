2. CENTRALIZED UTILITY ARCHITECTURE
--------------------------------------------------------------------------------
File: src/utils/formatCurrency.js

Features:
- formatCurrency(amount, options):
  * Utilizes Intl.NumberFormat('en-IN', { style: 'currency', currency: 'INR' }).
  * Dynamically detects fractional amounts:
    If (numericValue % 1 !== 0), minimumFractionDigits: 2, maximumFractionDigits: 2.
    If integer (whole rupees), minimumFractionDigits: 0, maximumFractionDigits: 0.
  * Explicit options.includeDecimals flag supported for overrides.
  * Gracefully handles null, undefined, empty strings, and NaN, returning '₹0'.
- parseCurrencyInput(value):
  * Sanitizes monetary inputs, stripping commas, whitespace, and currency symbols.
  * Strictly converts valid input into a clean JavaScript Number for MongoDB/API payloads.
  * Returns NaN for invalid inputs, ensuring validation rules trigger correctly.
  * Prevents comma-formatted strings from breaking numeric parsing or validation.
